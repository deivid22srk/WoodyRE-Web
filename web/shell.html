WoodyRE

engine de Woody Woodpecker: Escape from Buzz Buzzard Park no navegador — reverso por jjmhalew, port web em WebAssembly

Jogar

O engine roda 100% no seu navegador. Nenhum arquivo do jogo é distribuído aqui: para jogar você fornece uma imagem ISO do seu próprio CD do jogo (ou uma pasta com a cópia dos arquivos Data, Common, Logo, Game e Music.bf) quando o jogo pedir. Os arquivos ficam só no seu computador/navegador — nada é enviado a nenhum servidor.

Arquivos do jogo

O WoodyRE precisa dos arquivos do CD original (versões: inglês 1.00, espanhol, brasileiro, polonês ou russo). Escolha uma das opções:

…ou arraste a ISO aqui

A cópia verifica cada arquivo (SHA-1, 232 arquivos, ~640 MB) e acontece só uma vez. Em celular a memória pode não bastar — prefira o computador.

Aviso legal: você deve possuir uma cópia original do jogo. Nenhum arquivo protegido por direitos autorais é distribuído nesta página; os arquivos que você escolhe permanecem no seu navegador e não são enviados a nenhum servidor. Projeto não oficial, sem vínculo com Eko Software, Cryo Interactive, Microïds ou Universal Studios.
