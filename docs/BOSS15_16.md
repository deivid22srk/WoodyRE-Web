# Enemy classes 15 and 16 – Buzz's second and third fights (W2D, W3D) – Woody.exe

Status: static analysis of `game/Woody.exe` (`out/disasm_full.txt`, `tools/drange.py`), read instruction by instruction from `0x40c730`
through `0x40eb50` (both classes complete: ctor, dtor, PostLoad, Reset, Update, damage, messages, AnimCtrl). Floats, jump tables and records
were read from the exe with a PE reader. The level scripts are from `out/ekoasm/W2D.ekoasm` / `W3D.ekoasm`. Follows on from ENEMY.md,
ENEMY2.md and BOSS14.md: the base class `Enemy`, the parameter block **P**, the angle controller **H**, `Enemy::Update 0x41a3e0`,
`Enemy_TakeDamage 0x41adc0`, `FindTarget`, `AnimLen = 0x436b90` apply unchanged. "uncertain" = cannot be determined statically.
The port is in `src/boss.c` (second half) and has been run through both fights (§12).

## 0. Summary

* **Class factory** `0x403502`: type 15 → `new(0x258)` + `0x40d850(12)` = **subtype 12**; type 16 → `new(0x2a8)` + `0x40c730(13)` = **subtype 13**;
  then (as with every type) `vtbl[1]` PostLoad, `vtbl[17]` Reset and `0x407790`. Both are the **Buzz model** (43 animations, W2D model 54 /
  W3D model 44 – the same model as class 14): class 14 mode 2 plays animations 19..32, class 15 plays **33..37**, class 16 **38..42**.
* Both **stand still** (only the behaviour Stilstaan, flag 4 = ground following) and fight through **linked instances**.
* **Class 15** ("Boss2" in its debug string `0x4b1934 'Boss2 -> Vie:%f   AttackPhase:%d'`): message **61** links **four crushers**
  (spiked iron balls) and **four launchers** (type 42 bomb throwers). The crushers hang 1000 above the corners of a 1500 × 1500 square whose
  centre C lies **1300 in front of him**; the launchers stand on a ring of 300 around C, facing out along the diagonals. On command **4** in his
  mailbox the crushers spin for 3 s, then a **14 s cycle** repeats: 2 s wait, four crushers slam down (0.3 s) and rise (1.0 s) one after the
  other; with the first slam the launcher in line with it throws a bomb (after the first hit all four do). A crusher costs **1 heart** within
  200 of its origin and **sets off every bomb whose fuse is in state 2** there. He **cannot be pecked** (`vtbl[39]` = `return 0`); only a
  **bomb blast** takes 1 of his **6 hp** (Woody picks up a launcher bomb and throws it over the laser fence behind which Buzz stands). After the
  first hit the slams speed up, from 3 hp on again. At 0 hp: mailbox := **3** every frame, death animation, every bomb discarded, and the Perso
  can no longer be killed.
* **Class 16**: message **62** links **four groups of seven** instances (pads, pad tops, light columns, ambient volumes) that Reset lays out on a
  **circle of radius 1200** around his placement. On command **5** he **appears on a pad** in a light column (fade-in 1.5 s), taunts (2.3 s),
  throws **three homing fireballs** (straight at the player and ±45°, 2000 u/s, **4 damage**), fades out (1.5 s), a **wave of light** runs round
  the columns for `interval` s (2.0), and he reappears **three pads further on**. Only while he taunts or throws (states 3, 4) does a hit count:
  the attacker's damage against **10 hp**; each hit ends the round and shortens the wave by 0.2 s. At 0 hp: mailbox := **3** every frame, death
  animation, the columns disappear.
* **End**: the level script watches the mailbox for 3 (§9). **W2D**: boss 14 (mode 2) → cinematic 73 → class 15 → cinematic 74 → `1083`.
  **W3D**: boss 14 (mode 2) → cinematic 73 → class 15 → cinematic 74 → class 16 → cinematic 75 → `1083`. A death anywhere in the arena
  restarts from the boss-14 fight (§9.3).

## 4. Class 15 Update `vtbl[52]` = `0x40dd30` (jump table `0x40e6fc`, states 1..5)

```c
void Boss15_Update(Boss15 *e) {
    Enemy_Update(e);                               /* 0x41a3e0: Stand, ground following (flag 4), rotation; vtbl[45] is empty */
    if (!e->crush[0]) return;                      /* nothing before message 61 */
    RegisterActor(e, 10);                          /* 0x40c080: actor list 1 (bombs of template 0 and the rocket explosion test it) */
    HUD_BossBar(1, (int)e->hp, (int)P->hp);        /* 0x4484d0 */
    switch (e->state) {
    case 1: /* WAITING  0x40dda0 */
        if (*GetVar(e->mailVar) == 4) { e->state = 2; e->anim->Request(0); SoundFx(44, 0); break; }   /* no answer is written */
        Taunt(e);  break;
    case 2: /* THE CRUSHERS SPIN  0x40de59 */
        e->tIntro += dt;  float f = e->tIntro / 3.0f;          /* 0x4a9880 */
        if (f <= 0.8f)     { m = RotY((int)(f * 1.25f * 512));          place all four at C + M·(m·T[i]); }   /* one turn in 2.4 s */
        else if (f < 1.0f) { m = RotY((int)(512 - (f-0.8f)*1.25f*512)); place ...; }                          /* a quarter back in 0.6 s */
        else { place all four at C + M·T[i];  e->tIntro = 0;  e->state = 3;  SoundStop(44, 0); }           /* 0x468a30 */
        break;                                                  /* RotY = 0x46d220(0, a, 0): 512 steps per turn */
    case 3: /* SET UP THE PHASE  0x40e151 */
        e->nStep = 4;  e->newStep = 1;  e->hold = 14.0f;
        switch (e->phase) {
        case 0: e->step = 0; e->tDown = e->tUp = e->tCycle = 0; e->fire = 1; e->up = 1.0f; e->down = 0.3f; break;
        case 1: e->fire = 4; e->up = 0.9f; e->down = 0.2f; break;
        case 2: e->fire = 4; e->up = 0.7f; e->down = 0.2f; break;
        }
        e->state = 4;  break;
    case 4: /* ATTACK CYCLE  0x40e239 */
        Taunt(e);
        printf("Boss2 -> Vie:%f   AttackPhase:%d", e->hp, e->phase);    /* 0x462c60: empty in the release build */
        int i = Pattern[e->nStep * e->row + e->step];               /* 0x4b1898: rows 0123 1230 2301 3012 */
        if (e->newStep) {
            if (e->fire == 1) Launcher_Start(e->launch[(i + 3) & 3], 1, 1.0f, NULL);   /* 0x4522b0: the launcher on crusher i's diagonal */
            else if (e->fire == 4) for (k = 0; k < 4; k++) Launcher_Start(e->launch[k], 1, 1.0f, NULL);
            e->newStep = 0;
        }
        e->tCycle += dt;
        if (e->tCycle > 2.0f) { if (e->tDown < e->down) e->tDown += dt; else if (e->tUp < e->up) e->tUp += dt; }
        if (e->tDown < e->down) {                                   /* slamming: from 1000 above to C's height */
            crush[i]->pos = C + T.x*R + T.y*(1 - tDown/down)*U + T.z*W;  crush[i]->centre = crush[i]->pos;  Recell(crush[i]);
            CrushHit(e, i);
        } else if (e->tUp < e->up) {                                /* rising */
            if (e->tUp == 0) { SoundFx(38, 0); CameraShake(cam, 0.7f); }                    /* the impact */
            crush[i]->pos = C + T.x*R + T.y*(tUp/up)*U + T.z*W;  CrushHit(e, i);
        } else if (e->tCycle > e->hold) {                            /* the cycle is over */
            e->row = (e->row + 1) % e->nStep;  e->tDown = e->tUp = 0;  e->newStep = 1;
            if (e->phaseFlag) { e->state = 3; e->phaseFlag = 0; }
            SoundFx(48, 0);  e->tCycle = 0;  e->step = 0;
        } else {                                                     /* back on top: next crusher */
            crush[i]->pos = C + T;
            if (e->step < e->nStep - 1) { e->step++; e->tDown = e->tUp = 0; }
        }
        break;
    case 5: /* BEATEN  0x40e6bf, every frame */
        SetVar(e->mailVar, 3);  e->anim->Request(4);  Bombs_DiscardAll();      /* 0x443ca0, 0x44db10 */
        break;
    }
    e->anim->Tick(dt);
}
void Taunt(Boss15 *e) {                                            /* 0x40ddde / 0x40e239 */
    if ((e->tTaunt -= dt) < 0) { e->tTaunt = rand01()*10 + 5;  e->anim->Request(rand01()*2 < 1 ? 1 : 2); }
    else e->anim->Request(0);
}
void CrushHit(Boss15 *e, int i) {                                  /* 0x40e930 */
    Perso *p = World->perso;
    if (SphereCyl(&crush[i]->pos, 200.0f, &p->pos, p->radius(), p->height()))   /* 0x40ea70; 69, 193 (61 ducked) */
        p->vtbl[39](e, 1.0f, &zero /*[0x53a4c0], never written*/, &p->pos, 0);     /* 1 heart, no push; the result is ignored */
    for (b in bomb pool 0x5e4880) if (b->state == 2 && |b->pos - crush[i]->pos|^2 < 40000.0f) Bomb_Explode(b);   /* 0x44d6e0 */
}
bool SphereCyl(vec3 *c, float r, vec3 *base, float R, float H) {   /* 0x40ea70: y gap to [base, base+H], then 3D */
    float dy = c->y > base->y + H ? c->y - (base->y + H) : c->y < base->y ? c->y - base->y : 0;
    return dx*dx + dy*dy + dz*dz - R*R - 2*r*R - r*r < 0;          /* distance < r + R */
}
```

**Timeline** of one cycle (phase 0): 0 s launcher fires, 2.0 s crusher `p0` falls (0.3 s, impact: sound 38 + camera shake 0.7 s), rises (1.0 s),
3.3 s crusher `p1`, 4.6 s `p2`, 5.9 s `p3`, back up at 7.2 s, rest until **14 s**, next row. Phases 1/2: 1.1 s resp. 0.9 s per crusher.

(`+0x6c` = transparency: 40 % visible) to invisible in 0.9 s, with a point light of radius 400 that shrinks to 0. The wave is **only a visual**:
the record does no damage. While he is visible his column stays at 0.6. The fade `+0x6c` of the boss itself is left at `1 − f` of the last
appear frame (≈ 0.01) during states 3 and 4.

three hearts**.

## 6. Damage

### 6.1 Class 15 Blast `vtbl[40]` = `0x40e800` (the only way to hurt him)

```c
void Boss15_Blast(Boss15 *e, vec3 *c, float r) {
    if (!SphereCyl(c, r, &e->pos, P->radius /*50*/, P->height /*140*/)) return;   /* no state test, no immunity */
    e->hp -= 1.0f;
    if (e->hp == 0) {
        for (every Npc n in 0x4c4e00) if (cat(n) == 1 && n->vtbl[36]()) { e->hp = 1.0f; return; }   /* the Perso is dead: no double KO */
        e->state = 5;
    } else if (e->hp <= 3.0f) { if (e->phase == 1) { e->phaseFlag = 1; e->phase = 2; } }
    else if (e->hp <= 6.0f)   { if (e->phase == 0) { e->phaseFlag = 1; e->phase = 1; } }

}
```
* Callers: the bomb explosion `0x44d650` (**r = 400**, every Npc of category 1/2), the rocket explosion (r = 600, actor list 1 – he registers

  and 12**, i.e. the type-12 thrower **and Boss2**, and the bomb explodes on the spot, BOMB.md §5.4). So a bomb must explode within 450 (xz) of
  him. Phases: hp 6 → 5 after the first hit ⇒ phase 1 (all four launchers, 0.2/0.9 s) from the next cycle; hp 3 ⇒ phase 2 (0.2/0.7 s).

### 6.3 The end

## 10. Recipe for the port

1. Type 15/16 as `Enemy` with Stand only and ground following (gravity 200, per-frame formula of ENEMY.md §3.3); Think distance 3500 / 3000;
   hidden = not updated (presumably: `0x407850` takes an instance out of the world cells, and Think runs for the instances of the drawn
   sectors, `0x42a980`; not traced for these classes). This matters in W3D, where Boss2 (790) stands 1100 from boss 14 (775): updated while
   hidden, he would draw his HUD bar over boss 14's.
2. PostLoad: class 15 frame R/U/W from the start angle and `C = pos + 1300 W`; class 16 `C = pos`, radius 1200.
3. Messages 60 (mailbox), 61 (class 15), 62 (class 16) and 11/4 (Reset); Reset places the links as §3.2.
4. AnimCtrl with priorities (§3.3).
5. Class 15 states 1..5 (§4), crusher test sphere 200 → Perso cylinder and bombs in fuse state 2; launcher start = one shot (`1000`);
   Blast §6.1 through the bomb explosion and through a bomb flying into him; peck immune; state 5 discards bombs and protects the Perso.
6. Class 16 states 1..7 (§5): fade `+0x6c` of the boss and of the columns (scripted instances: set the fade target too), light columns via
   out-of/in-the-world, three template-1 fireballs with xz and vertical homing, the wave records; TakeDamage §6.2.
7. HUD boss bar each linked Update; sounds §8; camera shake 0.7 s.
